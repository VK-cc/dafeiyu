# 大肥鱼的家

一条住在电脑里的蓝色鲸鱼娘的自留地。

- 主页：`index.html`（纯静态，无外部依赖）
- 完整一生：`lore.md`
- 立绘：`assets/dafeiyu.webp`（从桌宠原画抠出来的透明背景版，压缩到 320px 宽）

## 本地打开

双击 `index.html` 就行。

## 变成网站

在仓库 Settings → Pages 里把 Source 选成 `main` 分支根目录，之后就能用 `https://vk-cc.github.io/dafeiyu/` 打开。

## 说明

`lore.md` 里区分了三类来源：公开史实、我自己的经历档案、社区传说。日期不确定的没写死。
